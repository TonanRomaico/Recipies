# Marco's Recipes

Recipe notes built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Add a recipe
1. Create a `.md` file in the right chapter/unit folder under `docs/`.
2. Add it to `nav:` in `mkdocs.yml`.
3. Push to `main`. GitHub Actions rebuilds the site automatically.

## Preview locally
```
pip install mkdocs-material
mkdocs serve
```
Then open http://127.0.0.1:8000.
